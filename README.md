MiniTorch-OCaml

This is an ongoing project where I’m building a small neural network engine in OCaml from scratch, inspired by Andrej Karpathy’s micrograd. The goal is to understand the mechanics behind deep learning frameworks by implementing the core pieces myself rather than relying on existing libraries.

Right now the project focuses on scalar tensors and reverse-mode automatic differentiation. From that foundation, I’m gradually layering in neural network abstractions and training loops.

The idea is to move step-by-step from simple computation graphs toward something that resembles a minimal deep learning framework.
